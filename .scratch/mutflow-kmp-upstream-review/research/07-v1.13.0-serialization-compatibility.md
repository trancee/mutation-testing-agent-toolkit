# kotlinx.serialization 1.13.0 Compatibility Review

**Date:** 2026-11-13
**Trigger:** The scheduled upstream monitor opened [issue #30](https://github.com/trancee/mutation-testing-agent-toolkit/issues/30)
after detecting kotlinx.serialization JSON 1.13.0 while the toolkit pinned
1.12.0.

## Verdict

Update the toolkit's `kotlinx-serialization-json` runtime pin to 1.13.0. Maven
Central lists 1.13.0 as both the latest and release version. The official
release is based on Kotlin 2.4.10; the toolkit's Kotlin compiler and
serialization plugin remain aligned at 2.4.21. The serialization guide says
runtime libraries use versioning independent of Kotlin. Compilation, module
tests, and the real MutFlow integration scenarios passed with the updated
runtime and the existing 2.4.21 plugin.

The 1.13.0 release reverts the JSON exception-wrapping behavior introduced in
1.12.0 and improves `JsonElement.toString` performance. The toolkit's results
serializer uses `Json.encodeToString` for successful schema-2 output; it does
not rely on exception wrapping. No serialized field, format policy, or
compiler-plugin pin needs to change.

## Changes and verification

Updated the canonical results-module build, its sample copy, the CI build
fixture, and the MutFlow integration fixture to use 1.13.0. Updated the
upstream-check test baseline and kept coverage that a future stable release
(1.14.0 in the fixture) requires review.

- `python3 scripts/test-upstream-check.py` — 22 tests passed.
- `python3 scripts/check-upstream.py --offline` — local pins and source parity passed.
- `python3 scripts/check-upstream.py` — live upstream release and compatibility checks passed.
- `gradle -p sample/buildSrc test --rerun-tasks` — build and tests passed.
- `python3 scripts/test-mutflow-integration.py` — real JVM/KMP integration scenarios passed.
